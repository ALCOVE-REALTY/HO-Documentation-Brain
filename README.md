# HO Documentation Brain

Alcove Realty head-office documentation: find the physical property files (company, project, location, cabinet), look inside their Drive folders, read, print and share the documents.

- **Website:** https://alcove-realty.github.io/HO-Documentation-Brain/
- **Android app:** [HO_Documentation_Brain.apk](HO_Documentation_Brain.apk) (allow "Install unknown apps" on the phone)

The Brain itself is a Google Apps Script web app. It is open only to people who sign in with an `@alcoverealty.in` email and a 6-digit code; this repository holds only the page that shows it and the Android app.
